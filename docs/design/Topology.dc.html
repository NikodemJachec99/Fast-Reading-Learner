How navigation behaves
Tabs keep their own scroll position. Switching is a lens slide, never a push.
Settings is a push with a glass back button and edge swipe.
A round is a full-screen cover. Quit asks once, then returns to where it started and saves the round as not completed.
Result: Next text starts a new round of the same exercise. Back to Today closes the cover.
Dashed lines: data, not navigation.
